# Use AgentVela as your default browser

On macOS, you can set the AgentVela desktop app as your default web browser so links from other apps and local HTML files open directly in AgentVela.

## Enable

Choose **AgentVela** in **System Settings → Desktop & Dock → Default web browser** (switch back there anytime).

## How links open

- If the active thread has its browser panel open, the link opens as a new tab there; otherwise AgentVela opens a new no-project thread with the browser panel maximized so you can ask an agent about the page right away.
- Pull request links for connected projects open in the PR view (when **Open pull requests in AgentVela** is enabled).
- [Prompt links](./prompt-links.md) to your self-hosted web UI open as a draft.
